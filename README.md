## Project Details

### 1. Random Password Generator

A Python program that generates random passwords based on the user's chosen length. It uses uppercase letters, lowercase letters, numbers, and special characters to create passwords.

### 2. BMI Calculator

A Python program that calculates a user's Body Mass Index (BMI) using their weight and height. It then classifies the BMI into categories such as Underweight, Normal, Overweight, and Obese.
 
### 3. Voice Assistant

A Python-based voice assistant that responds to user commands. It can greet the user, display the current date and time, and perform Google searches based on user input.
